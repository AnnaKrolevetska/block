# BLOK — Homepage

Односторінковий лендинг для київського девелопера житлових комплексів **BLOK**: «Простір для тих, хто йде вперед».

Темна тема, «скляні» (glassmorphism) елементи, акцентний лаймовий колір і великі типографічні заголовки. Чистий HTML + CSS + трохи JavaScript, без фреймворків і збірки.

---

## Структура сторінки

| Секція | Що містить |
|---|---|
| **Навігація** | Фіксована «скляна» панель з логотипом, посиланнями та кнопкою «Записатись» |
| **Hero** | Повноекранне фото, координати Києва, блок із кількістю мешканців і рейтингом, головний заголовок та дві кнопки |
| **Marquee** | Рядок, що біжить: Архітектура — Інфраструктура — Спільнота — Прозорість |
| **Маніфест** (`#manifesto`) | Історія бренду + фото з підписом |
| **Проєкти** (`#projects`) | Сітка з 6 карток: RIVER, PARK, HILL, LOFT, YARD, SKY — локація, координати, статус |
| **Lifestyle** | Bento-сітка з інфраструктурою двору: рутоп, коворкінг, фітнес, закритий двір |
| **Відгуки** | 6 карток із фото, цитатою та мешканцем |
| **CTA** (`#contact`) | Запис на приватний перегляд і завантаження презентації |
| **Футер** | Навігація, проєкти, контакти, соцмережі |

## Технології

- **HTML5 + CSS3** — один файл, усі стилі в `<style>`
- **Vanilla JS** — `IntersectionObserver` для анімації появи секцій (`.reveal` → `.in`)
- **Google Fonts**:
  - [Archivo](https://fonts.google.com/specimen/Archivo) — заголовки
  - [Inter](https://fonts.google.com/specimen/Inter) — основний текст
  - [IBM Plex Mono](https://fonts.google.com/specimen/IBM+Plex+Mono) — eyebrow-підписи та координати
- **Зображення** — [Unsplash](https://unsplash.com) (через CDN-посилання)

## Дизайн-токени

Усі кольори й радіуси винесені в CSS-змінні на `:root`:

```css
--bg:            #0A0A0B;   /* основний фон */
--bg-alt:        #131315;   /* фон marquee */
--text-primary:  #F5F4EF;
--text-muted:    #9A999E;
--lime:          #D6FF3F;   /* головний акцент */
--orange:        #FF5B2E;   /* додатковий акцент (поки не використовується) */
--radius-lg:     20px;
--radius-md:     12px;
```

Повторювані компоненти: `.glass` (скляна підкладка), `.btn-lime`, `.btn-glass`, `.eyebrow`.

## Адаптивність

| Брейкпойнт | Зміни |
|---|---|
| `> 1024px` | Десктоп: проєкти в 3 колонки, lifestyle 4×2, відгуки в 3 колонки |
| `≤ 1024px` | Планшет: маніфест в одну колонку, проєкти й відгуки у 2 колонки |
| `≤ 640px` | Мобільний: ховається меню навігації, усе в одну колонку, кнопки на всю ширину |

Також підтримується `prefers-reduced-motion` — для користувачів, які вимкнули анімації, marquee зупиняється, а секції з'являються одразу.

## Запуск локально

Збірка не потрібна — достатньо відкрити файл у браузері:

```bash
git clone https://github.com/<username>/<repo>.git
cd <repo>
open index.html        # macOS
# або
start index.html       # Windows
```

Або через локальний сервер:

```bash
npx serve .
# чи
python3 -m http.server 8000
```

## Публікація на GitHub Pages

1. Завантажте всі файли в корінь репозиторію (**Add file → Upload files**).
2. Зробіть push у гілку `main`.
3. У репозиторії: **Settings → Pages → Source: Deploy from a branch → `main` / `(root)`** → Save.
4. За хвилину-дві сайт буде доступний на `https://<username>.github.io/<repo>/`.
